# 音楽サービスのアイコン

各社のブランド素材ページから公式アイコンを入手して、このフォルダに次の名前で置いてください。
置けばアプリに出ます（置くまではブランド色の丸に記号を出しています）。

| ファイル名 | 入手先 |
|---|---|
| `service_spotify.png` | Spotify Design & Branding Guidelines（developer.spotify.com/documentation/design） |
| `service_appleMusic.png` | Apple Music Marketing Tools / Apple Music Identity Guidelines |
| `service_youtubeMusic.png` | YouTube Brand Resources（YouTube Music のアイコン） |

- 正方形・透過 PNG・一辺 180px 以上を推奨（表示は角丸の四角に収めます）
- 置いたあとは `xcodegen generate` をしてからビルド
- 各社の規約（色・余白・改変禁止など）に従ってください
