# Pastel UI assets

Approved prototype assets reused in the main StreetMelody Web app.

- `hero.png`: original mint bird with lilac headphones walking through a pastel street; main welcome panel and login.
- `cozy-room.png`: lavender armchair and record player; daily melody card.

Both were generated with the built-in image_gen tool. The current original bird hero prompt is retained in `hero-generation.md`; the room prompt is retained in `../../prototype/README.md`. The existing mascot stays as the user's avatar so avatar decoration behavior is preserved.
